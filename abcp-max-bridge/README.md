# Мост «Заказы ABCP → чат сотрудников в MAX»

Схема: ABCP уже умеет слать уведомление о новом заказе в Telegram-группу
(EmployeeAlerts). Мост слушает эту Telegram-группу и дублирует каждое новое
сообщение в групповой чат сотрудников в MAX.

```
ABCP → Telegram-группа (уже настроено) → мост → чат сотрудников в MAX
```

> **В проде сейчас используется готовый бот [@MaxTelegramBridgeBot](https://t.me/MaxTelegramBridgeBot)**
> (сторонний сервис, добавлен в Telegram-группу и в чат MAX как обычный
> участник, настраивается без своего кода — через диалог с самим ботом).
> `telegram_to_max_bridge.py` из этого набора — собственная reference-
> реализация той же схемы на Python: пригодится, если готовый бот окажется
> недоступен, сменит условия, либо понадобится свой контроль над форматом
> пересылаемых сообщений. Работает как фоновый процесс на Windows-ПК,
> который обычно включён.

## 0. Важное условие для MAX

Чтобы создать бота в MAX, нужен **верифицированный профиль организации, ИП
или самозанятого** в кабинете «MAX для партнёров» (dev.max.ru) — платформа
доступна только резидентам РФ. Если такого профиля ещё нет, его придётся
завести первым делом — без него токен бота не выдадут.

## 1. Telegram-сторона (источник)

1. В Telegram напишите **@BotFather** → `/newbot` → следуйте подсказкам →
   получите токен вида `123456789:AA...`.
2. Добавьте этого бота в ту же Telegram-группу, куда ABCP шлёт оповещения
   о заказах.
3. Отключите privacy-режим, иначе бот не будет видеть чужие сообщения в
   группе: у @BotFather выполните `/setprivacy` → выберите вашего бота →
   **Disable**. (Либо сделайте бота администратором группы — тоже работает.)
4. Узнайте `chat_id` этой группы — проще всего:
   - напишите любое сообщение в группу после добавления бота;
   - откройте в браузере
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates`;
   - в ответе найдите `"chat":{"id": -100XXXXXXXXXX, ...}` — это и есть
     `telegram_source_chat_id` (число отрицательное, с `-100` в начале).

## 2. MAX-сторона (получатель)

1. Зайдите в кабинет **MAX для партнёров** под верифицированным профилем
   организации и создайте бота — платформа выдаст токен доступа.
2. Дождитесь модерации бота (без неё бот может не работать).
3. Добавьте бота в групповой чат сотрудников MAX, куда должны падать
   уведомления о заказах.
4. Узнайте `chat_id` этого чата с помощью вспомогательного скрипта
   `get_max_chat_id.py` из этого набора:
   - откройте `get_max_chat_id.py` и впишите токен бота в
     `MAX_BOT_TOKEN` (или передайте его аргументом при запуске);
   - запустите: `python get_max_chat_id.py`;
   - пока скрипт работает, добавьте бота в чат (или, если чат уже есть —
     удалите и заново добавьте бота, чтобы событие `bot_added` пришло);
   - скрипт напечатает `chat_id` — это `max_target_chat_id`.

## 3. Настройка моста

1. Установите Python 3.10+ на ПК, если его ещё нет: https://python.org
   (при установке отметьте галку «Add python.exe to PATH»).
2. Установите зависимость:
   ```
   pip install requests
   ```
3. Скопируйте `config.example.json` в `config.json` в этой же папке и
   впишите четыре значения:
   ```json
   {
     "telegram_bot_token": "...",
     "telegram_source_chat_id": -100XXXXXXXXXX,
     "max_bot_token": "...",
     "max_target_chat_id": 123456789
   }
   ```
4. Проверьте вручную:
   ```
   python telegram_to_max_bridge.py
   ```
   Напишите тестовое сообщение в Telegram-группу ABCP — оно должно
   появиться в чате MAX в течение нескольких секунд. Остановите
   (Ctrl+C) после проверки.

## 4. Автозапуск на Windows

Самый простой вариант — запускать через `start_bridge.bat` (входит в
набор): он же перезапускает скрипт, если тот упадёт по сети.

1. Положите папку с ботом куда-нибудь постоянно (например,
   `C:\Bots\abcp-max-bridge\`).
2. Нажмите Win+R → `shell:startup` → Enter — откроется папка автозагрузки.
3. Создайте в ней ярлык на `start_bridge.bat`.
4. При следующем входе в Windows мост запустится автоматически и будет
   работать в фоне, пока ПК включён и вы вошли в систему.

Более надёжный вариант — через Планировщик заданий Windows (задание с
триггером «При входе в систему», действие — запуск `start_bridge.bat»,
опция «Перезапускать при сбое»); полезно, если ПК настроен на
автовход без ручного логина.

## Ограничения этой схемы

- Уведомления идут, только пока ПК включён и вы в системе вошли — если
  компьютер выключен или спит, сообщения из Telegram накопятся и
  придут в MAX сразу после включения (ничего не теряется, но есть
  задержка).
- Если у бота Telegram включён privacy-режим — он не увидит сообщения
  ABCP в группе, поэтому шаг 1.3 обязателен.
- Лимит текста сообщения в MAX — 4000 символов; более длинные
  уведомления ABCP будут обрезаны.
